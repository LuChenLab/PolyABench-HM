# the uniform default of 0.5.
#

# (`apa-polya-predict -t`); per-model values below can be applied by
# binarising the *_prob output columns at the listed cutoff. For

# validation-MCC-optimal threshold listed below (Human 0.46 / Mouse 0.43),
